📈 Real-Time Orderbook Viewer with Order Simulation
A Next.js application that connects to live orderbook data from OKX, Bybit, and Deribit using WebSockets. Simulate order placements and visualize market impact with a clean, responsive UI.

🚀 Features
🔄 Real-time orderbooks (15 levels) from OKX

🪝 WebSocket integration for instant updates

🧠 Zustand-based global state store

🖱️ Venue switcher (OKX, Bybit, Deribit) with animated tab UI

📱 Responsive and sleek layout

🎯 Modular, readable code

📦 Tech Stack
Next.js 14 (App Router)

TypeScript

Zustand – lightweight global state

WebSockets – real-time updates

CSS Modules – scoped, themeable styling
